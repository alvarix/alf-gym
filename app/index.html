Workouts

Where you are: all your workouts. Each workout (e.g. Workout 9.2) is one designed program. Revisions are sibling workouts linked by lineage: tap a workout to open its days, or fork a workout to start a new revision.
  1. Tap + new workout to start the wizard.
  2. Tap an existing workout to open its days.
  3. Toggle show archived to refer back to past workouts.

New workout

What this creates: one Workout, the Days you ticked, and (with skeleton on) blocks named after movement patterns. Blocks start empty so you can add exercises into them next.

Add day
Where you are: the days inside this workout. Each Day groups blocks. Alts (Day A alt - home) are siblings under the same letter.
  1. Tap a Day to open its blocks.
  2. Empty Days say empty · tap to design. Use them to practice.
  3. Tap fork to copy this whole workout into a new revision (e.g. 9.2 -> 9.3).

Add block
Where you are: blocks of one Day. Each block runs as linear or circuit.
  1. Tap a block to add or edit exercises.
  2. Use ⇄ to flip linear ↔ circuit.
  3. Reorder with ↑ ↓.

Add exercise
Where you are: exercises inside one block. Each row is a target prescription: sets, reps, side, load.
  1. Tap + exercise. Type a name; existing names autocomplete, new names create a new exercise.
  2. Set sets, reps, load. ^15 cable, (35) plate per side, ! via the notable checkbox.
  3. Save. The exercise appears numbered {block}.{i}.
