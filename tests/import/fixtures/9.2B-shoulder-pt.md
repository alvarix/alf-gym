# Shoulder PT

## 0. Shoulder PT

- [ ] *Serratus Wall Slide (band)*
    Band at wrists, forearms on wall pointing up, protract shoulder blades, slide arms up.
    10-2

- [ ] *Band Pull-Apart*
    :20!20-3

- [ ] *Face Pull (cable)*
    ^15!15-3

## 1. Shoulder Stability

3 rounds. Same KB, same spot. 90s rest between rounds.

- [ ] *Bottoms-Up KB Press*
    20!8-3

- [ ] *Half-Kneeling KB Press*
    20!:8-3
    Alt: Seated DB Press (when shoulder allows)

- [ ] *Prone Y-T-W*
    :5-3
    Cue: Pinch shoulder blades, hold 2s at top

- [ ] *[Bear crawl](https://example.com/bearcrawl)*
    10-3
    Cue: Neutral spine, hips level

- [ ] *Glute Amnesia Drills*
    8-3

## 3. Core + Carry

### Notes

Substitution guide for future KB swaps: match the total load. When shoulder allows, progress to overhead press variations. Re-evaluate KB weight each 4-week block.
