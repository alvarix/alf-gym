Speech feasibility summary

Web Speech API

Free, in-browser, no infra. Works on Chrome desktop and Android. Spotty on iOS Safari, often broken in standalone PWA mode. Custom grammar via SpeechGrammarList has limited support.

Whisper fallback

Record audio with MediaRecorder, ship to a transcription endpoint (Whisper API or Cloudflare AI). Costs per minute. Reliable cross-platform. Adds latency and a backend dependency.

Recommendation

Ship Web Speech in v1.1 for short notation utterances. Keypad always available as primary entry. Plan Whisper fallback in v1.2 once iOS standalone reliability matters.
